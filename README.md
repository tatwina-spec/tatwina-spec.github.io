# Catrina Ramirez Bayer — Digital Portfolio

A responsive, static portfolio built with HTML, CSS, and JavaScript. All personal images, certificates, poster art, and the résumé PDF are stored locally in `assets/`.

## Preview locally
Open `index.html` in a web browser. For a local server, run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `YOUR-USERNAME.github.io` (replace with your GitHub username).
2. Upload **all contents** of this folder to the repository root. Make sure `index.html`, `style.css`, `script.js`, and the `assets` folder are at the top level.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**; select `main` and `/ (root)`, then Save.
5. Wait for the Pages deployment to finish. Your site will be available at `https://YOUR-USERNAME.github.io/`.

If you use a repository with a different name, the address will usually be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.
